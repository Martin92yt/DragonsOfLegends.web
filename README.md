# ⚔️ Dragons of Legends — Web Demo

**The official showcase application for the [`dragons-of-legends.js`](https://github.com/Martin92yt/DragonsOfLegends.js) library.**

> ⚠️ **Under Development**
> This application is currently provided as a reference and showcase demo. Some features may be experimental, and the demo version may occasionally lag behind updates to the core library.

---

## 🔒 Privacy & Security

Authentication currently relies on simple **username and password credentials** to persist your character session.

Please note that this project is a **proof-of-concept demo** and is **not intended for production use**. Advanced security measures are not currently implemented and will be introduced in future updates.

For this reason:

- Session data is currently exposed and **not encrypted**.
- Do **not** use real, sensitive, or personal passwords.
- Do **not** use credentials that you reuse on other services.
- Avoid storing any sensitive personal information in the application.

---

## 🚀 Local Deployment

To run the demo locally, follow these steps:

### 1. Clone the repository

Clone or download the project to your local machine.

### 2. Install dependencies

```
npm install
```

### 3. Start the development server

```
npm run start
```

### 4. Open the application

Once the server is running, open your browser and visit:

```
http://localhost:3000
```
